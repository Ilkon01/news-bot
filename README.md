# Персональный новостной бот

Проверяет ваши Telegram-каналы и мировые новости раз в ~15 минут и присылает
в личный Telegram-бот только то, что подходит под ваши темы.

## Что нужно сделать один раз (займёт ~10 минут)

### 1. Создайте бесплатный аккаунт GitHub (если ещё нет)
https://github.com/signup

### 2. Создайте новый приватный репозиторий
Например `news-bot`. Важно: **Private**, чтобы токены не были видны никому чужому.

### 3. Загрузите туда все файлы из этой папки
Через веб-интерфейс GitHub (кнопка "Add file → Upload files") или через git —
как вам удобнее. Структура должна остаться такой же, включая папку
`.github/workflows/`.

### 4. Добавьте три секрета
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | `8962535201:AAEBLl4g2nwsMmshjDuKy9Zltp3NpE1RNsY` |
| `TELEGRAM_CHAT_ID` | `5096024468` |
| `ANTHROPIC_API_KEY` | ваш ключ с https://console.anthropic.com/settings/keys |

**Про ANTHROPIC_API_KEY** — это не тот же аккаунт, что подписка на claude.ai.
Нужно отдельно зарегистрироваться на console.anthropic.com, привязать карту
и создать ключ (Get API keys → Create key). Оплата идёт по факту использования —
при вашем объёме (несколько десятков коротких проверок в сутки) это будут
центы, не доллары.

### 5. Разрешите Actions запускаться по расписанию
**Settings → Actions → General → Workflow permissions** — выберите
"Read and write permissions" (это нужно, чтобы бот мог сохранять state.json
обратно в репозиторий и не слать одну и ту же новость дважды).

### 6. Проверьте вручную
**Actions → News bot → Run workflow** — запустите один раз кнопкой, чтобы
убедиться, что всё работает. Если что-то не так — в логах запуска будет видно,
на каком шаге ошибка.

Дальше бот будет запускаться сам каждые 15 минут.

## Как менять источники и темы

Открываете `config.yaml` прямо в GitHub (кнопка карандаша) — редактируете —
Commit changes. Ничего больше делать не нужно, следующий запуск подхватит
изменения.

- Добавить/убрать Telegram-канал — строка в `telegram_channels`
- Добавить RSS-источник — строка в `world_news_rss`
- Изменить темы фильтра — `filter_topics.include` / `filter_topics.exclude`
  (пишите просто своими словами, ИИ-фильтр поймёт)

## Важные ограничения, о которых стоит знать

- **Telegram-каналы** читаются через публичную страницу `t.me/s/<канал>` —
  это официально доступная всем страница предпросмотра, вход в ваш личный
  аккаунт не требуется. Работает только для публичных каналов.
- **Reuters и AP** официально не отдают RSS с 2020 года — в конфиге они
  подключены через поиск Google News по этим сайтам за последний час,
  это рабочий обходной путь, но если Google изменит формат — могут перестать
  обновляться. Al Jazeera и BBC отдают RSS напрямую и надёжнее.
- **Задержка** — GitHub Actions иногда откладывает запуск по cron на
  несколько минут при высокой нагрузке на их стороне, но обычно 15-минутный
  интервал даёт задержку доставки в пределах ваших 30 минут.
- Всё под вашим контролем: токены — ваши, репозиторий — ваш, код открыт
  и его можно менять как угодно.
